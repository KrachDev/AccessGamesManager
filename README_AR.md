# مدير الألعاب - AccessGames Manager

تطبيق سطح مكتب حديث وخفيف الوزن لنظام Windows يساعدك في إدارة وتنظيم مكتبة الألعاب الخاصة بك مع دعم قوي لـ Steam وإدارة الحسابات والتحكم المتقدم في جدار الحماية.

![الترخيص](https://img.shields.io/badge/الترخيص-MIT-green)
![الحجم](https://img.shields.io/badge/الحجم-42.84MB-brightgreen)

## 🎮 المميزات

### المميزات الأساسية
- **إدارة مكتبة الألعاب** - نظّم وأدر مجموعة ألعابك بالكامل
- **دعم حسابات متعددة** - بدّل بين حسابات اللعب المختلفة بسلاسة
- **تكامل Steam** - تكامل مباشر مع واجهة برمجيات Steam للبيانات الحية
- **إعدادات متقدمة** - خصّص حظر جدار الحماية وأوضاع الإطلاق والتفضيلات
- **التحكم في جدار الحماية** - احجب الألعاب من الوصول للشبكة بضغطة زر واحدة
- **التحديثات التلقائية** - تحديثات تطبيق تلقائية بدون تدخل المستخدم
- **دعم لغات متعددة** - دعم عدة لغات بما فيها العربية والإنجليزية

### الأداء
- ⚡ **خفيف الوزن** - فقط 42.84 MB كملف تنفيذي واحد
- 🚀 **بدء سريع** - تجميع ReadyToRun لإطلاق فوري
- 💾 **ذاكرة منخفضة** - وقت تشغيل محسّن مع تقليص جزئي
- 📦 **مكتفي ذاتياً** - لا توجد متطلبات أو حاجة لـ .NET SDK على أجهزة المستخدمين

## 📥 التثبيت

### التحميل
1. حمّل أحدث نسخة من `AccessGames Manager.exe` من [الإصدارات](https://github.com/KrachDev/AccessGamesManager/releases)
2. شغّل الملف التنفيذي - لا يوجد تثبيت مطلوب!
3. ابدأ في إدارة ألعابك فوراً

### متطلبات النظام
- **نظام التشغيل**: Windows 7 SP1 أو أحدث
- **المعمارية**: 64-بت (x64)
- **الذاكرة**: 500 MB على الأقل (1 GB موصى به)
- **التخزين**: 50 MB مساحة حرة

## 🚀 البدء السريع

### الإطلاق الأول
1. شغّل `AccessGames Manager.exe`
2. ربط حسابك على Steam
3. امنح صلاحيات جدار الحماية (قد تظهر مطالبة أمان Windows)
4. ابدأ في تنظيم مكتبة الألعاب الخاصة بك!

### الاستخدام الأساسي
- **عرض الألعاب**: استعرض مجموعة الألعاب الكاملة الخاصة بك
- **تبديل الحسابات**: اضغط على زر الحساب للتبديل بين ملفات اللاعب
- **حظر الألعاب**: حدد لعبة وبدّل حظر جدار الحماية
- **البحث**: استخدم وظيفة البحث للعثور على الألعاب بسرعة
- **الإعدادات**: خصّص اللغة وسلوك جدار الحماية وتفضيلات الإطلاق

## 🔧 معلومات البناء

### مكدس التكنولوجيا
- **.NET 9.0** - أحدث إطار عمل .NET
- **Avalonia 11.3.10** - إطار عمل واجهة مستخدم حديث
- **SteamKit2** - تكامل واجهة برمجيات Steam
- **Newtonsoft.Json** - تسلسل JSON
- **MVVM Community Toolkit** - دعم نمط MVVM

### تكوين البناء
تم تحسين المشروع لتقليل الحجم:
- ملف تنفيذي واحد
- تجميع ReadyToRun
- تقليص وقت تشغيل جزئي
- ضغط مفعّل
- بدون رموز تصحيح أخطاء
- هدف Windows x64

### البناء من المصدر

**المتطلبات الأساسية:**
- .NET 9.0 SDK أو أحدث
- Visual Studio 2022 أو Visual Studio Code

**استنساخ والبناء:**
```bash
git clone https://github.com/KrachDev/AccessGamesManager.git
cd AccessGames\ Manager
dotnet build -c Release
```

**النشر (بناء نحيف):**
```bash
cd "AccessGames Manager"
dotnet publish -c Release -r win-x64 --self-contained `
  -p:PublishSingleFile=true `
  -p:PublishReadyToRun=true `
  -p:PublishTrimmed=true `
  -p:TrimMode=partial `
  -p:EnableCompressionInSingleFile=true `
  -o "..\bin\PublishSlim"
```

**التشغيل:**
```powershell
.\bin\PublishSlim\AccessGames Manager.exe
```

## 🔐 تفاصيل المميزات

### إدارة الحسابات
- بدّل بين حسابات Steam متعددة فوراً
- خزّن بيانات اعتماد الحسابات بأمان
- تبديل سريع للحساب بدون إعادة تشغيل التطبيق
- دعم حسابات Steam المحدودة والكاملة

### تكامل جدار الحماية
- تكامل جدار حماية Windows Defender
- حظر لعبة واحدة بضغطة زر
- إدارة قواعد تلقائية
- عمليات حظر/إلغاء حظر جماعية

### مكتبة الألعاب
- عرض جميع الألعاب المثبتة من Steam
- مزامنة مكتبة حية في الوقت الفعلي
- إمكانيات البحث والتصفية
- تفضيلات إطلاق الألعاب

### الإعدادات
- **اللغة**: العربية والإنجليزية والمزيد
- **التحديثات التلقائية**: فعّل أو عطّل التحديثات التلقائية
- **جدار الحماية**: قم بتكوين سلوك الحظر الافتراضي
- **وضع الإطلاق**: اختر تفضيلات إطلاق الألعاب
- **المظهر**: دعم الوضع الفاتح والمظلم

## 🐛 استكشاف الأخطاء

### التطبيق لن يبدأ
- تأكد من Windows 7 SP1 أو أحدث
- تحقق من أن معمارية النظام هي 64-بت
- حاول تشغيل البرنامج كمسؤول

### مشاكل اتصال Steam
- تحقق من تثبيت Steam وتشغيله
- تحقق من اتصال الإنترنت
- أعد تشغيل التطبيق
- امسح ذاكرة التطبيق المؤقتة

### قواعد جدار الحماية لا تعمل
- شغّل البرنامج كمسؤول
- تحقق من تفعيل جدار حماية Windows
- تحقق من صحة مسار الملف
- راجع سجلات أمان Windows
